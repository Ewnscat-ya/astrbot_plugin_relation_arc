# 多维关系弧线（P0）

独立 AstrBot 插件：为 **Bot 人格 → 平台用户** 维护六维关系账本，并使用关系状态影响回复风格。

## 已实现

- 默认全局关系：同一平台用户的私聊/群聊共用账户；可在配置中关闭，改为会话隔离。
- 六维：信赖、认可、安心感、情感亲近、共鸣、恋爱意向。
- LLM `<relation_judgment>` JSON 附录解析、正文剥离、证据核验、十分位小数结算。
- 同事实递减、高值饱和、互动安全状态限制恋爱意向、滚动窗口防刷。边界压力是安全原因，不是关系维度。
- 群聊仅在唤醒、@ Bot 或引用回复时写关系；非定向消息仍会剥离控制块。
- `/关系`、`/关系记录`；管理员可用 `/修改关系维度 <用户ID> <维度> <值>` 和 `/增减关系维度 <用户ID> <维度> <变化>`。
- Pages：配置、账户摘要、脱敏审计、备份。

## 上游来源与许可

Favour Ultra 是本插件的**灵感与代码上游**，本项目是源自它的衍生项目（Apache-2.0 规划口径）。独立插件名与独立运行数据不改变代码来源关系。继承代码的许可证、署名、修改声明与来源映射见 [docs/REUSE_DECISIONS.md](docs/REUSE_DECISIONS.md)（可证实上游快照 `2f2ec141`）。本仓库暂未收录上游仓库链接与 LICENSE/NOTICE 文件，对外分发前需由仓库所有者确认许可落位。

## 并行使用 Favour Ultra

插件不会读取或改写 Favour Ultra 的代码、数据库或配置。两者如果同时在同一会话启用自动裁决，会同时向模型注入各自的关系协议；请在同一会话只启用其中一个自动关系模块。

## 数据与回滚

数据独立保存在 AstrBot 的 `plugin_data/astrbot_plugin_relation_arc/`。禁用或删除本插件不会改动 Favour Ultra 数据。删除前可在 Pages 的备份页创建 SQLite 备份。

## 当前自动绑定与默认值

模型同轮输出合法的绑定提案且 `mutuality=clear` 时，后端会在配置路线资格、固定类型门槛、安全状态、排他与冷却等检查通过后自动写入正式关系账本。这是当前自动绑定行为，并非独立的人工二次确认；没有新增人工确认或提案状态机。恋爱路线策略与正式关系绑定是不同状态。

**冷却规则**：同一账户在同一 scope 内，某类型正式关系自 `ended_at`（结束时刻）起进入该类型的 `cooldown_hours` 冷却期；期内同类型重新绑定被拒绝并在审计中记 `binding_rejected:cooldown`。仅同类型同 scope 冷却，历史 ended 记录保留，只取最近一条判定。分数达标本身不绑定；合法双向明确提案经后端校验可同轮自动绑定。

`initial_values`、`romance.default_policy` 和 `romance.safety_default` 仅决定新账户的初始值/状态；成功保存后的热更新对后续新账户生效，不重写已有账户。旧账户缺失字段沿用历史默认值，既有显式迁移保留兼容行为。

互动安全支持管理员基础状态和有时限的自动提升；当前默认 `llm_auto`，模型不能降低管理员基础安全状态。自动衰减默认关闭，主动搭话与绘画白黑名单适配未在本批实现。本批修复不代表整个原始 P0 已完成。
